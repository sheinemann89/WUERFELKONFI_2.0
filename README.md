# WUERFELKONFI_2.0

Browseranwendung, die Google Maps mit bis zu drei GLB-Modellen kombiniert. Lade Modelle hoch, wähle das aktive Modell aus und verschiebe es per Klick auf der Karte oder mit den Positions-Buttons.

## Start

1. Trage deinen Google-Maps-API-Key in `index.html` in der Skript-URL ein (`YOUR_GOOGLE_MAPS_API_KEY`).
2. Öffne `index.html` in einem Browser oder starte einen lokalen Webserver (z. B. `python -m http.server`).
3. Lade deine drei `.glb` Dateien über die Upload-Felder hoch.
